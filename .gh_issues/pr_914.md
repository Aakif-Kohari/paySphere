## Description

PaySphere RBAC controlled which routes a user accessed, but once a manager had read:employees they saw every employee in the entire tenant. This PR adds a policy-based row-level security layer.

**Fix:** rls(resource, action) middleware factory (attaches req.rlsFilter from PolicyService.buildQuery, controllers merge in one line) and policy.seed.js (idempotent built-in policies: manager-department-scope and employee-self-scope for all existing tenants).

## Testing Performed

* All new files pass node -c syntax check.
* rls populates req.rlsFilter = { department: 'Eng' } for a manager in Engineering.
* rls sets req.rlsFilter = {} on PolicyService error, next() called (no 500).
* seedPolicies is idempotent - running twice creates no duplicates.

### Edge cases

* PolicyService DB error: caught, req.rlsFilter = {}, request continues.
* No active policies for role: buildQuery returns {}, no extra filter applied.
* Seed called before any tenants: iterates empty array, no-ops safely.
* Multiple policies: buildQuery OR-s all conditions together.

## API Documentation
