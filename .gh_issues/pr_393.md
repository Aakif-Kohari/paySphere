## Description

This PR offloads the generation of CSV and PDF reports to background Node.js `worker_threads`. 

Previously, constructing a large PDF using `pdfkit` or stringifying thousands of CSV rows was done synchronously on the main thread inside `reports.controller.js` and `payroll.controller.js`. Because Node.js is single-threaded, this CPU-intensive operation blocked the server from handling any other incoming HTTP requests until the file was completely generated.

By utilizing `worker_threads`, the CPU-heavy data crunching and drawing is isolated. The main thread remains highly responsive and asynchronous.

### Architectural Changes:
1. **Export Service:** Created `backend/src/services/export.service.js` as an abstraction layer for spawning `worker_threads` and passing message payloads.
2. **Worker Modules:** 
    * `backend/src/workers/pdf.worker.js`: Handles all `pdfkit` drawing logic.
    * `backend/src/workers/csv.worker.js`: Handles `csv-writer` logic.
3. **Controller Refactor:** Rewrote `downloadPDFReport` and `exportPayrollCSV` to gather the database payload, dispatch it to `exportService`, and asynchronously `res.send()` the returned Buffer/String back to the client.
