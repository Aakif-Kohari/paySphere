## Description

This PR implements WCAG 2.1 Compliance Audit & Fixes to ensure the PaySphere platform is accessible to all users, including those with disabilities.

Currently, the dashboard lacks proper keyboard navigation, text contrast ratios fall below standard on some components, and several non-native interactive elements (like `div` or `span` with `onClick` handlers) are invisible to screen readers and keyboard users. 

This update introduces `eslint-plugin-jsx-a11y` to the frontend pipeline to prevent future regressions. It also fixes all identified low-contrast text (e.g. `text-gray-400` -> `text-gray-500`), adds explicit `focus:ring` utilities for keyboard focus visibility on inputs and buttons, and converts non-native interactive elements into fully accessible components with `role="button"` and keyboard event listeners.

### Manually verified

* Entire dashboard is navigable and usable entirely via a keyboard (Tab/Shift+Tab).
* Focus rings are visible when interactive elements are focused.
* Color contrast ratios for text and backgrounds meet the 4.5:1 minimum standard.
* Previously non-accessible click handlers now respond to the "Enter" key and have `tabIndex={0}`.

### Edge cases considered

* Interactive `div` elements requiring both `onClick` and `onKeyDown`.
* Elements nested within forms needing associated labels.
* Buttons masquerading as anchor tags without valid `href` attributes.
