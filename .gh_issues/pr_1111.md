## Description

PaySphere's payroll calculation was hardcoded. This PR adds a data-driven formula engine that evaluates per-component salary formulas (e.g. HRA = basic * 0.40) in topological dependency order.

**Changes made:**
- formulaEngine.service.js (new) - evaluateAll() evaluates components in dependency order using Kahn's algorithm. validateComponents() does a dry-run check. No eval() - uses new Function with a character-level whitelist.
- salaryStructurePreview.controller.js (new) - POST /preview returns line-item results without writing to DB. POST /:id/validate validates a saved structure.
- salaryStructurePreview.routes.js (new) - RBAC gated at READ_PAYROLL.
- app.js - mounts the new router.
