## Description

PaySphere generated monthly payslips but produced no comparative analysis between payroll runs. Finance teams had no visibility into why payroll costs changed month-over-month or how actuals compared to budget.

**Fix:** Budget model (per-department monthly targets with unique compound index), varianceReport.service.js (MongoDB aggregation pipelines for MoM variance + 3-month rolling average forecast), varianceReport.controller.js (4 endpoints), varianceReport.routes.js (RBAC-guarded, mounted at /api/reports).

## Testing Performed

* All new files pass node -c syntax check.
* getMonthlyVariance returns delta and deltaPercent per department.
* getAnnualForecast returns actuals for completed months, projected for future.
* POST /api/reports/budget upserts - calling twice does not create duplicates.
* Invalid month param returns descriptive 400 error.

### Edge cases

* No payroll data for a period: aggregation returns [], departments is [].
* Zero previous-month gross: deltaPercent is null (division by zero avoided).
* Forecast with no history: projected is null, not a fabricated number.
* Budget not set for a department: budgetedGross and budgetVariance are null.

## API Documentation

New endpoints (auth + tenant scope required):
GET  /api/reports/variance?year=N&month=N -> { year, month, departments, totals }
GET  /api/reports/forecast?year=N         -> { year, forecast: [{month, actual, projected}] }
GET  /api/reports/budget?year=N&department=X -> { budgets: [...] }
POST /api/reports/budget { department, year, month, budgetedGross } -> Budget doc
