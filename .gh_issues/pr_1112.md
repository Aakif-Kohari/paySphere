## Description

There was no way to onboard more than one employee at a time. This PR adds a full streaming CSV import pipeline: upload, per-row validation, preview before commit, atomic transaction-backed insert, and rollback.

**Changes made:**
- employeeImport.model.js (new) - tracks job lifecycle, stores per-row errors, and holds imported employee IDs for rollback.
- employeeImport.service.js (new) - parseAndValidate() streams CSV through csv-parse. commitImport() inserts in 100-row chunks inside a Mongoose transaction. rollbackImport() deletes by importBatchId.
- employeeImport.controller.js (new) - four endpoints: start, poll, commit, rollback.
- employeeImport.routes.js (new) - multer in-memory storage, RBAC gated.
- app.js - mounts the new router.
