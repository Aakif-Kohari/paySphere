## Description

This PR implements the "Custom Company Logos on PDF Payslips" feature (Issue #386), allowing employers to white-label the generated PDF reports.

Instead of displaying generic text headers on the PDF reports, employers can now upload their company logo through the Settings page. This logo is safely stored as a Base64 string directly on the `User` schema and dynamically injected into the PDF generation worker thread.

### Architectural Changes:
1. **Model Update:** Added a `companyLogoData` string field to the `User` schema in `user.model.js`.
2. **Backend API:** Added `POST /api/users/settings/logo` in `user.routes.js`, leveraging `multer` to accept an image upload in memory and convert it into a base64 Data URL.
3. **Worker Thread:** `reports.controller.js` now fetches the employer's `companyLogoData` and passes it to `pdf.worker.js`. The worker thread intercepts this string, converts it back into a binary Buffer, and seamlessly embeds it at the top-left corner of the PDF using `pdfkit`.
4. **Frontend Integration:** Added a sleek image uploader interface in `Settings.jsx` under the Company Info section, displaying a live preview of the currently uploaded logo.
