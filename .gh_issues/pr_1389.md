## Description

This PR implements core-HRMS configuration features for custom schema field mapping.

* **Integration Field Map Model**: Schema storing tenant-specific mapping of external HRMS attributes to local Employee schema fields.
* **Controller / Routes**: Mounts get mapping `/api/integrations/:provider/mapping` and put mapping `/api/integrations/:provider/mapping` endpoints.
