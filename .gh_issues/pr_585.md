## Description

This PR introduces Multi-Tenant Architecture Support (Issue #585).

Currently, PaySphere isolates data loosely using the `createdBy` property on Mongoose models, acting as a proxy for tenant boundaries. This prevents true B2B SaaS scaling where multiple users (HR admins, managers, employees) belong to the same overarching company (Tenant).

This major architectural refactor implements a formal multi-tenant system:
- **Tenant Model**: Introduced a `Tenant` model to represent isolated company boundaries.
- **Model Isolation**: Added `tenantId` to all models (`Employee`, `Payroll`, `AuditLog`, `ReportSchedule`, `SalaryStructure`, `Loan`, `Attendance`, `Settlement`).
- **Auth Flow**: Updated the registration flow to provision a `Tenant` upon signup and inject the `tenantId` into the JWT payload.
- **Data Scoping**: Updated all API controllers and authentication middleware to automatically scope data queries (`.find`, `.findOne`) and creations using `req.tenantId` instead of the legacy `req.userId` pattern.

This lays the foundation for role-based delegation within the same company and full data isolation across different clients.
