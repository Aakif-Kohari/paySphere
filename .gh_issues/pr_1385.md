## Description

This PR implements role-based IP CIDR whitelisting and cryptographic session fingerprinting to enhance security. It blocks requests from non-whitelisting IPs for privileged roles (VPN/office subnet gating) and detects hijacked tokens via User-Agent/IP tracking in session cache.

* **IP Whitelist Model**: Schema defining whitelisted CIDR blocks per user role.
* **Session Fingerprint Middleware**: Calculates and validates SHA-256 context-based hashes.
* **IP Access Control Middleware**: Resolves tenant whitelist rules and validates incoming client IPs against them.
* **Controller / Routes**: Endpoint for managing IP Whitelists `/api/security/ip-whitelists`.
