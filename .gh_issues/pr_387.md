## Description

This PR implements the "Audit Log Viewer in the Dashboard" feature (Issue #387). 

Previously, security-critical events (like employee deletions and payroll finalization) were logged into the database via the `createAuditLog` mechanism, but there was no way for employers to view this history. This PR exposes these logs via a paginated API and renders a clean, intuitive data table in the frontend Settings page.

### Architectural Changes:
1. **Backend Route:** Added `backend/src/routes/audit.routes.js` and mounted it to `/api/audit-logs`.
2. **Backend Controller:** Added `getAuditLogs` in `audit.controller.js` which securely fetches `AuditLog` records filtered by `req.userId` with MongoDB sorting and pagination (`skip`/`limit`).
3. **Frontend Integration:** Added a new "Audit Trail" tab in `Settings.jsx`. Added React state for pagination (`auditPage`, `auditTotalPages`) and an effect to automatically fetch records on tab switch or page change.
4. **UI Updates:** Designed a responsive, dark-mode compatible HTML table to display the Timestamp, Action, Resource, and IP Address. Added "Next/Previous" pagination controls.
