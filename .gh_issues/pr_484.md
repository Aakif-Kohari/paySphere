## Description

This PR introduces Horizontal Scaling & Redis Integration (Tech Debt Issue #484).

Previously, rate limiters (`express-rate-limit`) stored state in Node's local memory. This prevented horizontal scaling as each node instance would have an isolated count of requests.

This update configures `rateLimiter.middleware.js` to use `rate-limit-redis`. By leveraging the existing Redis client configuration inside `cache.service.js`, the rate limiter now syncs request counts globally across all instances whenever `REDIS_URL` is provided. If `REDIS_URL` is omitted (e.g. for local dev), it falls back seamlessly to in-memory state.
