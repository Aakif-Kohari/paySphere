## Description

This PR introduces the Employee Turnover & Retention Metrics (Issue #482). 

Currently, PaySphere allows employers to manage active and terminated employees, but lacks high-level HR reporting on retention. 

This update provides a new "HR Metrics" tab within the Reports dashboard. It calculates the annualized Turnover Rate over the trailing 12 months, the Average Tenure (in months) of departed employees, and visually charts active headcount vs. monthly terminations using `recharts`. The backend correctly interprets soft-deletes via `deletedAt` for accurate historical state reconstruction.
