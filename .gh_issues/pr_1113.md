## Description

PaySphere had no subscription plan concept - every tenant got every feature. This PR adds the foundational plan and feature-flag layer.

**Changes made:**
- plan.model.js (new) - plan definition with features[] and limits.
- tenantSubscription.model.js (new) - per-tenant subscription with plan slug, status, and usage counters.
- featureFlag.middleware.js (new) - requireFeature() checks tenant plan features (60s cache), returns 402 on mismatch. Fail-open: errors never block requests.
- subscription.controller.js (new) - GET /api/tenant/subscription. Auto-creates basic trial on first access.
- subscription.routes.js (new) - auth gated.
- plan.seed.js (new) - idempotent Basic/Pro/Enterprise seed.
- app.js - mounts the new router.
