## Description

This PR implements Real-time Collaborative Payroll Adjustments via WebSockets (Issue #589).

Previously, if multiple HR administrators opened the Payroll Wizard concurrently, they could blindly overwrite each other's adjustments during finalizing. This change introduces real-time multiplayer collaboration to the payroll editing interface.

### Key Features
- **Socket.io Integration**: Added a dedicated `payroll.socket.js` WebSocket server on the backend to manage concurrent user sessions per month/year.
- **Active Users Presence**: The frontend now displays real-time avatars in the Payroll Wizard header for all admins currently editing the same payroll run.
- **Live Sync**: Any adjustment made by an admin (bonus, deductions, overtime, leaves) is instantly broadcasted to all other active admins in the room, seamlessly updating their UI state without page reloads.

## API Documentation (required for any new/changed backend endpoint)

No new REST endpoints, only WebSocket events:
- **`join_payroll_session`**: Triggers room join.
- **`active_users_update`**: Emits list of active users.
- **`payroll_adjustment_change`**: Client pushes an update.
- **`payroll_adjustment_sync`**: Server broadcasts update to room.
