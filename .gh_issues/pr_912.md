## Description

PaySphere is a multi-tenant SaaS platform where any authenticated user could read/mutate records belonging to other companies by knowing a MongoDB ObjectId. This PR adds the foundational tenant isolation and row-level security layer.

**Fix:** Four new modules - tenantGuard.middleware.js (IDOR prevention via post-fetch tenantId comparison), tenantPlugin.js (Mongoose schema plugin with pre-save guard and dev-mode pre-find warning), policy.model.js (RLS policy schema with condition DSL), policy.service.js (policy evaluator with 60s CacheService TTL).

## Testing Performed

* All new files pass node -c syntax check.
* tenantGuard returns 403 when doc.tenantId does not match req.tenantId.
* tenantPlugin rejects Model.save() that omits tenantId with a descriptive error.
* policy.service.buildQuery returns {} when no policies match the user role.
* policy.service.buildQuery returns { OR } when multiple policies apply.

### Edge cases

* Missing req.tenantId: guard returns 403, no data leakage.
* Missing res.locals.document: logs warning, calls next() (backward compatible).
* Policy DB error: caught, returns {}, controller tenant scope is the fallback.
* Template interpolation when user field is undefined: returns null, matches nothing.
