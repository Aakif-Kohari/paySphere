## Description

This PR fixes a privacy and compliance bug in the `deleteAccount` backend controller. Previously, deleting an account would remove the `User`, `Employee`, and `PayrollUpdate` records, but it orphaned the `AuditLog` records created by that user. 

This update ensures that all `AuditLog` documents associated with the user's `userId` are also deleted, fully cleaning up the user's footprint in the database and complying with standard data deletion practices.
