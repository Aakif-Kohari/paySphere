## Description

PaySphere's payroll approval chain had a race condition: two approvers acting simultaneously would silently overwrite each other. Rejection could proceed with no reason, leaving no audit context.

**Changes made:**
- payrollApproval.service.js (new) - advanceStage() uses MongoDB findOneAndUpdate with a __v version match. Stale update returns null and caller gets 409 Conflict.
- payrollApproval.controller.js (new) - POST /approve, POST /reject (requires non-empty comment), GET /approval-status.
- payrollApproval.routes.js (new) - RBAC gated: READ_PAYROLL for viewing, WRITE_PAYROLL for acting.
- app.js - mounts the new router at /api/payroll.
