## Description

This PR fixes a layout shift issue on the Settings page (`Settings.jsx`) that occurred when input and select fields received focus.

Previously, the fields used `focus:border-blue-500` which caused slight dimensional jumps in some browsers when the border color or style changed unexpectedly without a consistent base border width.

The focus styling has been standardized to use `focus:outline-none focus:ring-2 focus:ring-blue-500`, which applies a consistent box-shadow ring without affecting the element's box-model dimensions. This provides a smoother and more stable user experience.
