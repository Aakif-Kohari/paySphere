## Description

This PR replaces native browser `alert()` popups with non-blocking MUI `<Snackbar>` and `<Alert>` components in the frontend reporting and payroll flow.

Previously, when actions like PDF Download or CSV Export failed (e.g. no data available) in `Reports.jsx` and `MonthlyUpdates.jsx`, the application would trigger a native `alert()`. This blocked the UI thread, paused JavaScript execution, and created a jarring user experience.

By implementing MUI Snackbars, errors are now displayed gracefully in the bottom-right corner and auto-dismiss after 6 seconds, keeping the application responsive and modern.
