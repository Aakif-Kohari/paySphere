## Description

This PR introduces Report Scheduling (Issue #483).

Users previously had to manually generate and download payroll and analytics reports on a monthly basis. 

This update adds a `node-cron` background job engine and a new `ReportSchedule` Mongoose model. Users can now click "Schedule Report" from the Reports dashboard, select a report type (Analytics, HR Metrics, Payroll Data), specify a frequency (daily, weekly, monthly), and provide an email distribution list.

The background cron job checks the database daily at midnight for schedules that are due to run based on their `lastRunAt` timestamp and frequency, and systematically dispatches them.
