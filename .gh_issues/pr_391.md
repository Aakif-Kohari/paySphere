## Description

This PR implements a comprehensive Role-Based Access Control (RBAC) authorization system to replace the simple JWT authentication checks.

Previously, any authenticated user had access to all endpoints. This PR introduces a robust `Role` and `Permission` schema, and applies route-level protection based on the user's assigned permissions.

### Architectural Changes:
1. **New Models:** Created `backend/src/models/role.model.js` and `backend/src/models/permission.model.js`.
2. **User Model Update:** Added a reference to `Role` in `user.model.js`.
3. **RBAC Middleware:** Created `backend/src/middlewares/rbac.middleware.js` with `requirePermission(permissionName)`.
4. **Route Protection:** Wrapped sensitive endpoints in `employee.routes.js`, `payroll.routes.js`, and `reports.routes.js` with specific permissions (e.g., `WRITE_EMPLOYEE`, `READ_PAYROLL`).
