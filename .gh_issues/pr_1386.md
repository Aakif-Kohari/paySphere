## Description

This PR implements cryptographic document sealing and a public verification API to prevent forgery of employee payslips, Form 16, or contracts.

* **Document Seal Model**: Schema storing document SHA-256 hashes, signing metadata, and cryptographic signatures.
* **Cryptographic Seal Service**: Signs document contents using tenant-specific keys via HMAC-SHA256, and verifies seals.
* **Public Verification Controller & Routes**: Exposes unauthenticated `/api/public/verification/verify` route allowing third parties to check document hashes and verify data integrity.
