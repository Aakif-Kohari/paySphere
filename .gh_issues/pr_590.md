## Description

This PR introduces the foundation for the Advanced Workflow Engine for Multi-step Approvals (Issue #590).

Previously, approval logics (e.g., payroll, loans, overtime) were hardcoded boolean flags or simple status enums scattered across multiple controllers. This prevented companies from enforcing custom, N-step hierarchical approvals.

This PR establishes:
- **`Workflow` Schema**: Defines nodes (trigger, approval, condition, action) and directed edges for custom graphs.
- **`WorkflowInstance` Schema**: Tracks the real-time execution state of a specific document (e.g., Payroll `_id`), maintaining a rigorous audit history of who approved what node.
- **Workflow Controller/Routes**: A centralized state-machine executor that safely handles transitioning instances between nodes.
- **Frontend Skeleton**: Initializes the `WorkflowBuilder.jsx` drag-and-drop skeleton (React Flow integration will land in a follow-up commit/PR to keep diffs manageable).

This completely decouples the definition of an approval chain from the business logic models.
