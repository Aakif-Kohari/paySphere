## Description

This PR implements the Custom Report Builder (Issue #481). 

Previously, PaySphere only offered hardcoded PDF and CSV exports for Monthly Updates and Analytics. As companies grow, HR and Finance teams require highly specific custom reports (e.g., "Show me just the Overtime Pay for the Engineering department in Q3").

This update adds a dynamic Custom Reports tab in the Reports dashboard. It allows users to select datasets (Employees or Payroll Records), pick specific columns to include, and add dynamic filters. The backend endpoint `/api/reports/custom` securely parses these dynamic requirements into a Mongoose query, preventing NoSQL injection while returning customized data for preview and CSV export.
