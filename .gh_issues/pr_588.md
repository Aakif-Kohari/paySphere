## Description

This PR addresses Issue #588 by bootstrapping the migration to a Turborepo Monorepo and scaffolding the upcoming Native Mobile App via React Native (Expo).

Previously, PaySphere consisted of two isolated directories (`frontend` and `backend`). This PR introduces a modern Workspace architecture using NPM Workspaces and Turborepo, allowing us to seamlessly share business logic between the web app and the mobile app.

### Key Changes
- **Root Monorepo Setup**: Added a root `package.json` utilizing NPM Workspaces to manage `frontend`, `backend`, `apps/*`, and `packages/*`. Added `turbo.json` to orchestrate build and lint pipelines across the entire repository.
- **Shared Package Extraction**: Initialized a `@paysphere/shared` package under `packages/shared`. This acts as the foundational internal library where we will migrate shared utilities, Typescript interfaces, and API services currently duplicated across platforms.
- **Mobile App Scaffold**: Initialized a barebones React Native Expo project in `apps/mobile/`. It successfully imports and renders logic from `@paysphere/shared`, proving the monorepo internal linking works flawlessly.

Note: The existing `frontend` and `backend` directories were explicitly kept in their original locations to prevent breaking existing CI pipelines or Dockerfiles. They are simply assimilated into the workspace layout.
