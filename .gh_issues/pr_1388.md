## Description

This PR implements the Payroll Reconciliation & Anomaly Resolution Center to allow auditing and override controls over flagged anomalies before payroll finalization.

* **Payroll Reconciliation Model**: Tracks resolved/overridden anomalies along with managers justifications and timestamps.
* **Reconciliation Guard Middleware**: Intercepts the payroll finalize endpoint and blocks execution if unreconciled HIGH or CRITICAL anomalies are found.
* **Controller / Routes**: Mounts endpoints to log a reconciliation entry `/api/payroll/reconcile` and read audit logs `/api/payroll/reconciliations`.
