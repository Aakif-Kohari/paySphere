## Description

This PR implements the requested "Pagination and Search" feature for the Employees Management view (Issue #385).

While the Dashboard overview had a basic search input, the "Employees" tab was missing a way to filter employees by name/role, which became a significant pain point for employers with over 50 staff members. Additionally, although the backend supported server-side pagination, the UI was previously not taking full advantage of it across all views.

### Architectural Changes:
1. **Frontend Integration:** Added the search input directly to the header of the `EmployeeManagement` view within `Dashboard.jsx`.
2. **State Management:** Passed the `search` and `setSearch` props from the parent `PaySphereDashboard` component down to the `EmployeeManagement` component.
3. **Backend Logic:** Validated that `employee.controller.js`'s `getEmployees` function already perfectly handles `$regex` queries across the `fullName` and `role` attributes, seamlessly returning the filtered and paginated result set using MongoDB's `skip` and `limit`.
